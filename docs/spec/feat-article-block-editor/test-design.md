# テスト設計 (P04)

- feature: `feat-article-block-editor`
- phase: P04

## 1. 方針

**振る舞いだけを見る。** pixel 位置・DOM 構造・クラス名に依存した検証を書かない。
見るのは可視ラベル、アクセシブル名、保存されるデータの中身の 3 つ。

理由: この feature は編集面を作り直す。構造依存の検証を書くと、
見た目を直すたびに検証が落ちて、検証のほうを直すことになる。
それは「壊れていないのに赤くなる」検査であり、やがて誰も見なくなる。

## 3. 境界値

| 断片 | 境界 |
| --- | --- |
| `image-row` | 2 枚未満・4 枚超へ動かせない |
| `bullet-list` | 項目が 1 つのとき消せない |
| `comparison-table` | 最後の 1 行は消せない / 桁が足りない行を落とさない |
| `divider` | 中身が無くても残る |
| `callout` | 見出しが空・空白だけのときに空の強調を置かない |
| 画像 | 0 バイト / 8 MiB ちょうど / 8 MiB + 1 |
| 回収 | 24 時間ちょうど / 30 日ちょうど |
| 商品検索 | `q` が空 / 0 件 / 上限 8 件 |
