## `tests/integration/d1-seo-assessment.test.ts` (14)

`worker-runtime` プロジェクト。本物の SQLite で回す。

1. 同じ観点を 2 度診断しても行は 1 つで、中身は新しいほうになる
2. 根拠の無い指摘が 1 件混ざると、その回はまるごと保存されない
3. 出す順は重さ × 件数で決まる（重さだけで並べない）
4. 「直さない」と決めた指摘は、次の診断で復活しない
5. 理由の無い「直さない」は受け付けない
6. 下書きを作ると drafted になり、公開状態にはならない
7. 「直さない」と決めた指摘からは下書きを作れない
8. 他の workspace の指摘には触れない
9. 構えが未設定のブログは null を返す（既定値をでっち上げない）
10. 構えは上書き保存できる
11. 抽出し直すと、記事から消えた問いは表からも消える
12. 抽出 0 件は失敗ではない（引用できる形になっていない、という結果）
13. 問いか答えが空の単位は保存しない
14. 他の記事の単位は、抽出し直しても巻き添えにならない

11〜14 は AEO 側（`article_answer_unit`）と同じ表ファイルに同居している。
どちらも「改善層の保存」という同じ性質を確かめるので分けていない。

## `tests/domain/seo/guideline-reference.test.ts` (14)

- 89 日なら verified_fresh
- 90 日ちょうどは verified_fresh（「超えたら」見直し）
- 91 日で review_due になる
- 読めない日付は review_due に倒す
- 原典未取得なら、日付が新しくても verified_fresh を名乗らせない
- 見直し間隔は 90 日
- 4 件あり、全件に確認日と『全文は未取得』の但し書きがある
- id が重複していない
- 指紋が前回と変わっていれば、内容変更として出す
- A取得→B変更→B再取得でも警告を残し、B再評価完了後だけ消し、C変更で再発する
- 前回と同じ指紋なら出さない（取り直しただけで仕様を開かない）
- 期限切れと未取得が重なったら、期限切れを先に名乗る
- どの章の根拠でもない URL は、状態が悪くても再評価の対象にしない
- 対応表の URL は、すべて初期候補として登録できる URL である

10 番目が長いのは、**再取得と再評価の分離**を 1 本で辿るため。
A取得 → B変更 → B再取得（まだ警告は消えない）→ B再評価（消える）→ C変更（再発）。
分けて書くと、途中で消えてはいけないことが表現できない。

## `tests/application/seo/feeds.test.ts` (23)

- ホスト・ブログ基底パス・サイト内の道を、この順でつなぐ
- 道を渡さなければブログのトップになる（末尾に余計な / を足さない）
- AI クローラー 4 種を明示的に Allow する
- 既定の User-agent: * が Allow: / で始まる（4 種の前に、全部への許可がある）
- **遮断（Disallow）を 1 行も書かない**
- Sitemap の行がある
- Sitemap の行は最後に来る（注記の中に埋もれない）
- llms.txt を出すブログでは在り処の注記が付き、出さないブログでは付かない
- loc と lastmod が入り、URL の & が逃がされる
- 複数件が改行で並び、1 件ごとに url の対が立つ
- 1 件も無ければ、空の urlset を返す（壊れた XML にしない）
- 題名・説明の `< > \` （エスケープ）
- リンクは渡された道をそのまま使う
- 編集済み記事とブログ運用記事が、同じ 1 本の道を通る
- guid は link と同じ値を isPermaLink=true で持つ
- channel の link はブログのトップ（記事の URL ではない）
- pubDate は YYYY-MM-DD を UTC 0 時として RFC 822 で出す
- 読めない日付の記事は、pubDate の行そのものを出さない（壊れた日付を配らない）
- 1 件も無ければ item を出さず、channel は閉じる
- `# サイト名`・`> 説明`・`## 記事一覧`のリンク列の形になる
- Markdown なので、題の `< >` をエスケープしない（XML の逃がしを持ち込まない）
- 記事が 1 件も無くても、見出しの骨組みは残る
- ブログ運用で書いた記事も同じ形で並ぶ

**5 番目が受入条件 8 を満たさないことの固定**である。
遮断を書かないことをテストで留めてあるので、
黙って足すと赤くなる。
