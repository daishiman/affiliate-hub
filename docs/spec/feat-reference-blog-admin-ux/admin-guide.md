# 管理画面かんたんガイド

このガイドは、初めて使う運営者が説明なしでも主な作業を終えられるように、各作業を3段階以内にまとめる。画面内では青緑の主ボタンを1つだけ次の操作として扱い、補助操作と危険操作は分ける。

## 1. 記事を新しく作る

1. `/admin/blog/articles` で「記事を1本作る」を選び、用途に近い記事型を1つ選ぶ。
2. 題名・URL名・導入だけを入力して「下書きを作る」を選ぶ。ほかの項目は後から追加できる。
3. 記事画面で保存状態が「保存済み」と時刻を示したことを確認する。

## 2. 記事を改善する

1. 記事の詳細から「改善点を見る」を開き、重要度と該当箇所で絞る。
2. 1件を選んで変更前後をプレビューし、内容を確認して「この改善を反映」を選ぶ。
3. 合わなければ直後の「取り消す」で戻す。一括反映は全差分の確認後だけ使う。

## 3. 保存・失敗・競合を扱う

1. 画面上部の保存表示で「未保存・保存中・保存済み・失敗・競合」のどれかを文字とアイコンで確認する。
2. 失敗なら入力を残したまま「もう一度保存」、競合ならサーバー版と手元版の差分を確認して採用する側を選ぶ。
3. 再度「保存済み」と保存時刻が出たことを確認する。ブラウザー内の一時下書きは正常保存後に消える。

## 4. アフィリエイトを確認する

1. `/admin/inbox` で成果リンクを貼る。500ms後に自動確認が始まるので、先に保存操作をしない。
2. 正規URL・商品名・販売元・画像または図解・価格/取得時刻・取得元・重複・状態/理由・保存後の扱いを確認する。未取得値は推測せず手入力で補う。
3. 問題がなければ明示的に登録し、`/admin/affiliate/links` で掲載数を選んでサイト・ページ・ブロックを逆引きする。

## ローカル画面確認

- URL: `http://localhost:3000/signin`
- テスト用メール: `owner@local.test`
- パスワード: なし。ローカル専用の「owner@local.test として入る」を押す。
- 前提: `.dev.vars` の `DEV_SIGNIN_ENABLED=1`、`pnpm db:migrate:local`、`pnpm seed:local`、`pnpm dev`。

本番・development環境ではローカル専用ログインを使わない。表示されていた場合はセキュリティ事故として公開を停止する。
