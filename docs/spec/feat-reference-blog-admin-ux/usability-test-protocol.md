# Usability test protocol

- participants: 本system未経験者10名。実施者はnavigationやbutton位置を教えない。
- environment: desktop 1280px 5名、mobile 375px 5名、テスト用owner accountとseed data。
- tasks: (1)templateから下書き作成 (2)1改善案をpreview/apply/undo (3)保存済みか判別しreload復帰 (4)指定linkの掲載site/page/blockを特定。
- measurement: 完了/失敗、所要時間、誤操作、助言、保存判別、掲載先特定をparticipantごとに記録。
- pass: 主task完了、保存判別、掲載先特定がそれぞれ9/10以上、重大誤操作0。観察未実施を自動testで代用しない。
- evidence: participantを匿名IDで記録し、操作画面、expected/actual、所要時間、findingを `usability-report.md` へ記録。
