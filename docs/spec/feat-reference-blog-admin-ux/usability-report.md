## 実施台本

参加者へナビゲーション位置やボタン名を教えず、テストアカウントで次を依頼する。

1. テンプレートを選び、必須項目だけで下書きを作る。
2. 改善案を1件選び、差分確認、適用、取消しを行う。
3. 記事を保存し、保存済みか判断する。再読み込み後の復元も確認する。
4. 指定された成果リンクの掲載site/page/blockを特定する。

各人について匿名ID、表示幅、成否、所要時間、助言回数、誤操作、保存判別、掲載先回答、観察findingを記録する。個人名・メール・録画URLはrepositoryへ保存しない。

## 再開条件

10名の参加日時と同意が確保され、`usability-test-protocol.md` の記録項目を埋められること。結果が閾値未満ならUIを修正して別の初見参加者で再試験し、同じ参加者への説明後再試験で成功率を上書きしない。
