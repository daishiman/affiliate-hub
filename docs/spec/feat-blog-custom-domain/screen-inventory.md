# 画面の棚卸し — 住所

## 対象画面

| 経路 | 実装 | 役割 |
|---|---|---|
| `/admin/sites/[site]/domains` | `src/app/admin/sites/[site]/domains/page.tsx` | ブログ 1 本ぶんの住所の一覧・登録・切替・取り下げ |

## 画面が持つ節

1. **いま読者へ見せている住所** — 一覧の中の印ではなく、独立した節に文で出す。
   行が増えたときに印は見落とす。ここを読み違えると、切り替えたつもりで
   切り替わっていない住所を配り歩くことになる。
2. **既定住所の説明 (`Callout`)** — 独自ドメインが配信中でない間だけ出す。
   「独自ドメインが止まってもブログは読める」ことを明示する。
3. **DNS に置く設定** — 直前の操作が設定を返したときだけ出す。種類・名前・値に加えて
   **何のためか**を 1 列持つ。専門語だけの表は、置く人が判断できない。
4. **登録済みの住所** — 0 件なら `EmptyView`。各行は `BlogDomainRow`。
5. **住所を追加する** — `RegisterBlogDomainForm`。

## 行が持つ操作

`BlogDomainRow` は「状態を取り直す」「これを読者へ見せる」「取り下げる」の 3 つを
同じ行に並べる。同じ form に複数の submit があるため、意図は先頭の隠し欄
(`intent`) で区別する。取り下げには理由の記入を要求し、直近の失敗理由
(`lastError`) を行の補足として出す。

## 出さないもの

- ドメインの購入導線 (スコープ外)
- 他のブログの住所 (workspace 全体の一覧は別経路 `action: "read"` (siteSlug 省略))
