## 0. 出典と観測範囲 (ASM-001 の扱い)

- 参考サイトの URL は本書に載せない。`bd memories reference-blog` で引ける永続メモ と、2026-08-25 の利用者対話 (`system-spec/spec-state.json` qa_log `qa-*-web-site-blueprint`) だけが出典を保持する。
- 観測方法: 2026-08-25 に取得できた **トップページ 1 件** と **テーマ別サブサイトの比較記事 1 件** の静的 HTML、および sitemap index の存在確認 (投稿種別×年ごとの分割 + ニュース sitemap)。全ページの機械取得は本セッションで権限拒否されたため行っていない。
- したがって本書は「観測した事実」と「ナビ・フッター・パンくず・内部リンク目録から復元した推定」を **§2 の被覆表で区別** する。推定部分は取得が許可され次第、構造のみ照合し CHG として追記する (文章・画像は複製しない)。

## 1. サイト網の構造 (観測)

参考サイトは単一ブログではなく **ハブ + テーマ別サブサイト網** である。

```text
ハブサイト (総合レビュー)
 ├─ 上位カテゴリ A (ガジェット系 11 下位)         … ハブ内カテゴリ木
 ├─ 上位カテゴリ B (家電系 5 下位、うち 1 つはサブサイトへ委譲)
 ├─ サブサイト 1 (PC 系)      … 独自ドメイン配下パス、独自カテゴリ木 (2 階層)、独自 feed、独自サイドバー、独自の会社情報ページ
 ├─ サブサイト 2 (回線・通信系) … 同上 (下位 5)
 ├─ サブサイト 3 (ゲーム系)    … 同上 (下位 9)
 ├─ 用途別ナビゲータ (入口案内ページ)
 ├─ 用語辞典 (テーマ特化のミニサイト)
 ├─ 物販ページ
 └─ 法定・運営ページ群 (§2)
```

観測できた不変条件:

| 項目 | 観測値 |
|---|---|
| ヘッダーのブランド・メガナビ | ハブとサブサイトで **共通** (ロゴだけがサブサイト名に変わる) |
| カテゴリ木 | ハブは `/category/<上位>/<下位>/`、サブサイトは `/<sub>/category/<上位>/<下位>/` の 2 階層。ナビはハブ側から直接サブサイトの下位カテゴリを指す (横断リンク) |
| 記事 URL | ハブ `/<slug>/`、サブサイト `/<sub>/<slug>/` (日付なしスラッグ)。まとめ記事は `best-*` 命名規則 |
| feed | ハブ・サブサイトそれぞれに記事 feed とコメント feed |
| SEO 構造化データ | ハブ: WebSite / Organization。記事: Article + WebPage + Person + Organization + ImageObject + CollectionPage (カテゴリ) |
| AI 向け公開 | `llms.txt` / `llms-full.txt` を公開 (記事目録のテキスト版) |
| 関連メディア帯 | トップに「姉妹サイト 4 件」のカードを並べ、網の存在を利用者へ明示 |

## 4. 記事型テンプレート (ArticleTemplate 差し込み。06 §3-2 を上書き)

| 記事型 | 題名規則 | 本文部品列 (§3.3 の id) | 製品カード出現 |
|---|---|---|---|
| T1 まとめ (比較・ランキング) | 【年】用途 + おすすめ + N選 | 5→6→7→8→9→10×n→11→12→13→14→15 | 3 箇所 (紹介・比較・まとめ) |
| T2 単品レビュー | 製品名 + をレビュー + 要点 1 句 | 5→6→7→8→(外観・仕様 h2: 図版多)→(良い点 h2 / 気になる点 h2)→(こんな人向け h2)→13→14→15 | 冒頭と末尾の 2 箇所 |
| T3 ガイド・辞典項目 | 用語 + とは / 選び方 | 5→6→7→(定義 h2)→(判断軸 h3 × n)→(関連記事)→14 | 任意 |
| T4 ハブ (カテゴリ説明) | カテゴリ名 + まとめ | 説明 → 下位カテゴリ帯 → T1 へのタイル | 無し |

説明の仕方 (v1.0 反映方針 C を維持): 課題を吹き出しで代弁 → 判断軸を先に提示 → 軸ごとに図版 + 箇条書き → 比較で横断 → まとめで再掲。

## 9. 転用禁止の確認

本書は部品 id・件数・順序・URL パターン・見出し階層だけを記録し、参考サイトの文章・画像・固有名 (サイト名・製品名・ブランド名・人名)・色値・フォント・テーマ/プラグイン名を含まない。実装時も同様とし、`docs/product/ledgers.md` ASM-001 は「構造のみ観測・部分解消 (2 ページ + 目録)」へ更新する。
