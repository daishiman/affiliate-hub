# 運用手順（feat-blog-ui-builder）

## SEO / AI 指針の出典

1. `/admin/settings` から「SEO/AI 検索の指針」を開く。
2. 出典 URL・発行元・確認日を登録する。確認日から 90 日を超えた行は「再確認」と出る。
3. 再確認したら確認日を今日に更新する。
4. ガイドラインが変わったら、仕様セルを R4-reopen する（`ah-6lf.3`）。アプリのレジストリを直しただけでは仕様は動かない。

## IndexNow

1. 開発 / 本番の Worker 環境変数に `INDEXNOW_KEY` を置く。リポジトリ・管理画面・D1 には置かない。
2. 鍵ファイルは `https://<origin>/indexnow.txt` で公開される（所有権の証明そのもの）。
3. 鍵が無いときは記事公開は通り、通知だけ skip される。
4. Google は IndexNow 非対応。Bing 系（ChatGPT search の基盤）向け。

## llms.txt

- `/s/{site}/llms.txt` は設計図の任意項目。効果は未確認。Google は使わないと明言している。
- 出さない設定なら 404。

## ブログ UI テーブル

`0022` で 6 テーブルが作られる。指針レジストリ以外は画面から書けない（`ah-6lf.4`）。空の一覧を「壊れている」と誤認しないこと。
