# 表の可読性契約

- `caption` は目視可能で、何の集合かを 1 文で示す。
- `thead th` はスクロール中も `top: 0` で固定する。狭い viewport でも解除しない。
- 横スクロールする表は 1 列目を行見出し `th scope="row"` にし、`left: 0` で固定する。
- 左上の交差セルは header/row の両方より高い z-index を持つ。固定セルには不透明な surface を与える。
- 表の横移動は表コンテナだけに閉じ、ページ全体を二次元スクロールさせない。コンテナはキーボード focus 可能で名前を持つ。
- 数値は右寄せと tabular nums、状態は可視文字、操作は 44px 以上。情報を列見出しの色や位置だけに依存させない。
- 200% zoom でも列見出しと主キーの対応を失わない。カードへの自動変換でカラム名を消さない。
