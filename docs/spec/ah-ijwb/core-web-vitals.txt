## 判読

1. **10 経路すべてで LCP == FCP。**
   最大の要素が最初の描画と同時に出ている、つまり
   **後から入ってくる大きな要素（画像・遅延読み込み）が 1 つも無い。**
   数字としては最良だが、これは速さの成果ではなく
   「載っているものが少ない」ことの現れである。

2. **記事 `/s/home-office-desk/blog/starter-kit-2026` の DOM 215 / 転送 10KB は、
   ブログトップ（DOM 340）より小さい。**
   記事本文が 1 文字も出ていない（P11 で検出、E2E でも裏付け済み）ことと整合する。
   **本文が入れば LCP は必ず動く。いまの数字は本文が入る前のものである。**

3. CLS は全経路 0。ずれる要素そのものが無い状態なので、
   本文とアフィリエイト枠が入った後に取り直す必要がある。

4. `/tools/desk-chair-fit` は 404 のまま計測している（A4 の固定ページ 404 と同根）。
   404 ページの速さを測っても意味は無いので、この行は参考値である。
