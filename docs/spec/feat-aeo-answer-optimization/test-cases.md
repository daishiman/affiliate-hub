## `tests/application/seo/feeds.test.ts` — 23 件（normal）

### 道の組み立て
- ホスト・ブログ基底パス・サイト内の道を、この順でつなぐ
- 道を渡さなければブログのトップになる（末尾に余計な / を足さない）

### robots.txt
- AI クローラー 4 種を明示的に Allow する
- 既定の User-agent: * が Allow: / で始まる（4 種の前に、全部への許可がある）
- 遮断（Disallow）を 1 行も書かない
- Sitemap の行がある
- Sitemap の行は最後に来る（注記の中に埋もれない）
- llms.txt を出すブログでは在り処の注記が付き、出さないブログでは付かない

### sitemap.xml
- loc と lastmod が入り、URL の & が逃がされる
- 複数件が改行で並び、1 件ごとに url の対が立つ
- 1 件も無ければ、空の urlset を返す（壊れた XML にしない）
- 題名・説明の < > を逃がす
- リンクは渡された道をそのまま使う
- 編集済み記事とブログ運用記事が、同じ 1 本の道を通る

### rss.xml
- guid は link と同じ値を isPermaLink=true で持つ
- channel の link はブログのトップ（記事の URL ではない）
- pubDate は YYYY-MM-DD を UTC 0 時として RFC 822 で出す
- 読めない日付の記事は、pubDate の行そのものを出さない（壊れた日付を配らない）
- 1 件も無ければ item を出さず、channel は閉じる

### llms.txt
- \# サイト名・> 説明・## 記事一覧のリンク列の形になる
- Markdown なので、題の < > をエスケープしない（XML の逃がしを持ち込まない）
- 記事が 1 件も無くても、見出しの骨組みは残る
- ブログ運用で書いた記事も同じ形で並ぶ
